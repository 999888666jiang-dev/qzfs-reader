# 术语表

| 术语 | 含义 | 备注 |
| --- | --- | --- |
| 章节号 `n` | 原著章节序号 1–3,233 | 固定不变；缺失章也保留号位 |
| 章 id | `c` + 四位零填充，如 `c0001` | URL、书签、进度都用它 |
| 候选 | 扫描到的「第 N 章」标题及其正文切片 | 同一章号可能有多候选 |
| 伪标题 | 正文行内/缩进造成的假章节行 | 如 `　　` 缩进的重复标题、带广告的标题 |
| 选版 | 同一章号多个版本中选一份 | 规则见 `data-design.md` §7 |
| 缺失章 | 1–3,233 中没有可用正文的章 | 当前 132 章；生成占位 |
| 占位 | 缺失章的 JSON 与页面提示卡 | `missing: true`、`paras: []` |
| `⚹` 脱敏占位 | 源文件用 U+26B9 替换的原字 | 6,696 处；保留不改写 |
| 清洗 | 删除站点广告/BOM/页码/段首空格 | 不改写正文 |
| 导航分卷 | 每 100 章一组，仅目录导航 | 非原著分卷；关于页说明 |
| 目录 | 3,233 章的完整列表/抽屉 | 支持过滤、虚拟滚动 |
| 主题 | 六套阅读配色（paper/sepia/mint/night/oled/arcane） | 只改 CSS 变量 |
| 字号 | 正文 px 值 14–32 | 设置持久化 |
| 进度比例 | 章内滚动位置 0–1 | 用于恢复位置，避免绝对像素 |
| 书签 | 用户标记的章节 | 存 `qfs.bookmarks.v1` |
| 书架 | 书签 + 最近阅读 + 数据管理页 | 路由 `#/shelf` |
| hash 路由 | 用 `#/...` 表示页面，不请求服务器 | Pages 无需 404 重写 |
| PWA | 可安装、可离线的 Web 应用 | manifest + Service Worker |
| SW | Service Worker，缓存壳与已访问章节 | `prompt` 更新 |
| EffectBoundary | 包裹动效组件的错误边界 | 初始化失败显示静态兜底 |
| DoD | Definition of Done，完成定义 | 见 `spec-v1.md` §7 |
| R-xx | 需求规则编号 | 必须贯通需求→代码→测试→验证 |
| LCP / CLS / INP | 性能指标：最大内容绘制 / 布局偏移 / 交互延迟 | 预算见 `architecture.md` §13 |
| 降级 | 动效/能力不足时退回静态或简化 | 不得影响阅读 |
