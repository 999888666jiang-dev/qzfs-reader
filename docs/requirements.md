## 1. 项目与角色

- **项目**：单部小说《全职法师》（作者：乱）的个人阅读站，纯静态、无账号、无后端。
- **用户角色**：
  - 读者（本人）：在手机/桌面浏览器打开、读、调设置、记进度、加书签。
  - 维护者（本人）：重建语料、部署、更新、备份数据。
- **使用场景**：通勤/睡前用手机继续读；在电脑上大屏读；换设备时通过导出/导入迁移进度（v1 不做云同步）。

## 3. 操作流程

1. **首次打开**：首页显示书名、主图、「开始阅读」；点击进入第 1 章。没有本地数据时不报错。
2. **继续阅读**：再次打开首页，若有进度，显示「继续阅读 · 第 N 章」；点击回到上次章节与位置（误差 ≤5% 章长）。
3. **读一章**：阅读页显示章节号、标题、正文；底部有上一章/下一章；顶部有目录、书签、设置；滚动时进度条更新。
4. **调设置**：打开设置抽屉 → 选主题/拖字号 → 正文即时变化 → 关闭抽屉继续读；刷新后仍生效。
5. **找章**：打开目录 → 输入「2893」或「世界」→ 列表过滤 → 点击跳转；缺失章显示「原文缺失」。
6. **缺失章**：直接打开 `#/read/c2893` 或从目录点入，显示缺失提示卡，可去上一章/下一章，不显示空正文。
7. **书签**：在阅读页点书签图标 → 书架出现该章 → 从书架点击跳回 → 可删除。
8. **离线**：首次访问后开启飞行模式，已读过的章节仍可打开；未读章节提示离线不可用。新版本部署后，页面提示刷新。
9. **迁移**：书架页「导出备份」下载 JSON；另一台设备「导入备份」后，设置/进度/书签恢复。

## 5. 业务规则

- **R-01 首页与入口**：首页必须显示书名《全职法师》、作者「乱」、主视觉、「开始阅读/继续阅读」、以及目录、搜索、书架、设置、关于五个入口。无进度时主按钮为「开始阅读」并进入第 1 章；有进度时为「继续阅读 · 第 N 章」并回到上次位置。数据加载中显示骨架；加载失败显示重试，不白屏。
  - 验收：清空 localStorage 打开首页 → 显示「开始阅读」→ 点击落在 `#/read/c0001` 且正文可见。

- **R-02 章节打开与缺失**：`#/read/cNNNN` 可直接打开、刷新、分享；页面显示章节号、标题、正文段落、上一章/下一章。章节不存在（超出 1–3,233 或非 `cNNNN`）显示「章节不存在」并给返回目录按钮。标记为缺失的章节显示「第 N 章 原文缺失」提示卡与前后章按钮，正文区不得出现空白假段落或 AI 补写。
  - 验收：打开 `#/read/c2893` → 看到缺失提示，上一章/下一章可用；打开 `#/read/c9999` → 看到「章节不存在」。

- **R-03 字号**：阅读页可在 14–32 px 之间以 1 px 调整，提供「小 16 / 标准 20 / 大 24 / 特大 28」预设与「恢复默认」。调整后正文即时重排，设置持久化。360 px 宽视口在 32 px 字号下不允许出现横向滚动或文字被裁切。
  - 验收：390×844 设备调到 32 px → 无横向滚动；刷新 → 字号仍为 32；恢复默认 → 回到设备默认值。

- **R-04 阅读背景**：提供至少 6 套主题（纸白、羊皮纸、护眼绿、夜间、纯黑、魔法夜），切换立即生效并持久化；正文与背景对比度达到 WCAG AA（普通文本 ≥4.5:1，≥24 px 或粗体 ≥3:1）；首屏必须在 React 挂载前应用主题，刷新时不得先闪白/闪黑。
  - 验收：从纸白切到纯黑 → 背景 `#000`、正文浅灰；刷新 → 仍是纯黑且首帧无白闪；用对比度工具抽查 6 套主题均达标。

- **R-05 排版**：提供字体（宋体/黑体/系统）、行距 1.5–2.2、段距 0–1.5 em、页宽四档、两端对齐开关，均可即时生效、持久化、可一键恢复默认。正文段落统一缩进 2 em；源文件段首全角空格在构建期去除。
  - 验收：改行距 2.0、页宽「窄」、开启两端对齐 → 段落布局变化且无溢出；刷新保持；恢复默认后回到 1.85/medium/关闭。

- **R-06 目录与跳章**：目录必须列出 1–3,233 全部章节（含 132 个缺失占位），按 100 章一组分节；支持按章节号或标题即时过滤；缺失章显示「缺」标记且不可打开正文但可定位；当前章、已读、书签均有视觉标记；列表使用虚拟滚动，3,233 项滚动不卡顿；点击任意可用章跳转。
  - 验收：打开目录搜索「2893」→ 只出现缺失条目并标注；搜索「世界」→ 出现「第1章 世界大变」；清空搜索后列表从第 1 章开始；点击第 500 章 → URL 变为 `#/read/c0500`。

- **R-07 章节切换**：阅读页提供上一章/下一章按钮、键盘 ←/→、移动端左右滑动（阈值 ≥60 px）、以及章节轮盘（按钮或快捷键 `C`）。第一章的上一章、最后一章的下一章按钮禁用并提示「已经是第一章 / 已经是最后一章」。滑动不得干扰文本选择与纵向滚动；切换时不自动跳过缺失章（缺失章提示卡上可点下一章）；只有「继续阅读」命中缺失章时才跳到最近可用章并提示。
  - 验收：第 1 章按 ← → 按钮禁用并出现提示；第 3233 章按 → 同理；滑动 80 px 切到下一章；打开轮盘滚轮选择第 100 章 → 跳转。

- **R-08 阅读进度**：自动记录当前章节与章内滚动比例（0–1）；刷新、重开浏览器、从首页「继续阅读」都能恢复到同一章、位置误差 ≤5% 章长。未读完的章节切换后仍保留各自位置（至少最近 50 章）。当前章缺失时，继续阅读跳到最近的可用章并提示原章缺失。
  - 验收：在第 12 章滚到 50% → 刷新 → 位置在 45%–55%；回首页点继续阅读 → 回到第 12 章；切到第 13 章再回第 12 章 → 位置仍在 50% 附近。

- **R-09 书签**：阅读页可添加/取消当前章书签；书架页按添加时间倒序列出，显示章节号与标题；点击跳转，可单条删除或清空；全部持久化。重复添加同一章不产生重复项。
  - 验收：给第 12 章加书签 → 书架出现一项；再加一次 → 仍只有一项；刷新后仍在；删除后书架为空。

- **R-10 搜索**：提供独立搜索页与目录内过滤；输入 ≥1 个字符后 120 ms 防抖查询；支持章节号（如 `12`、`第12章`）与标题子串；结果高亮匹配片段，最多显示 200 条并提示总数；无结果显示「没有找到相关章节」；点击结果打开对应章。
  - 验收：搜「世界」→ 返回标题含「世界」的章节且高亮；搜「9999」→ 无结果提示；搜「第12章」→ 第 12 章置顶。

- **R-11 本地数据与迁移**：设置、进度、书签分别存入 `qfs.settings.v1`、`qfs.progress.v1`、`qfs.bookmarks.v1`；读取失败或结构不合法时回退默认值、备份原值、提示「本地数据损坏，已重置」，不阻塞阅读。书架页提供导出 JSON、导入 JSON、清空数据；导入前校验版本与结构，失败提示原因且不改动现有数据。
  - 验收：手工写入非法 JSON → 刷新 → 页面正常、默认设置生效、出现提示；导出 → 清空 → 导入 → 进度/书签/设置恢复；导入坏文件 → 提示失败且原数据不变。

- **R-12 动效与降级**：四类动效（首页描边标题、半调主图、光斑光标，阅读页章节轮盘）各有开关并持久化；`prefers-reduced-motion: reduce` 或设置 `reduceMotion=on` 时关闭动画，直接显示静态结果；WebGL2 不可用或初始化异常时，主图显示静态图、光标不加载、标题静态渲染，页面其余功能不受影响；触摸设备默认关闭光斑光标；低端设备（`deviceMemory ≤4` 或 `hardwareConcurrency ≤4`）默认关闭半调动画与光标。
  - 验收：模拟 `prefers-reduced-motion: reduce` → 无 GSAP 时间线、主图静态、页面可正常阅读；禁用 WebGL → 首页仍有完整主图与标题；关掉「标题动效」刷新 → 静态标题。

- **R-13 响应式与移动端**：360–430 px、768 px、1024 px、1440 px 均无横向滚动、无内容遮挡；工具栏按钮点击区 ≥44×44 px；底部导航适配 `env(safe-area-inset-bottom)`；移动端目录/设置为全屏抽屉，可用手势或返回键关闭；横屏不裁切正文。
  - 验收：360×800、390×844、768×1024、1024×768、1440×900 五档逐页检查无横向滚动；移动端按钮实测 ≥44 px；抽屉打开时背景不滚动。

- **R-14 路由与深链**：使用 hash 路由；`#/`、`#/read/cNNNN`、`#/shelf`、`#/search`、`#/settings`、`#/about` 可直接打开/刷新/前进后退；未知路由显示 404 页面与「返回首页」；路由切换不整页刷新，滚动位置按页面规则恢复（阅读页回顶部或恢复进度）。
  - 验收：新标签打开 `#/read/c0123` → 直接显示该章；地址改 `#/xxx` → 404；浏览器后退 → 回到上一页且状态保留。

- **R-15 PWA 与离线**：提供 manifest（名称、图标 192/512/maskable、`display: standalone`、主题色）与 Service Worker；已访问过的章节在离线时可打开；未缓存章节离线时显示「当前离线，本章尚未缓存」与重试；检测到新版本时提示「有新版本，点击刷新」，用户确认后更新；v1 不自动缓存全书（列为 v1.1）。
  - 验收：手机安装到主屏 → 图标与启动画面正常；访问第 1 章后开飞行模式 → 第 1 章可读；未访问的第 500 章 → 显示离线提示。

- **R-16 部署**：站点部署在 GitHub Pages 的项目子路径下（如 `/qzfs-reader/`）可正常打开；所有资源与数据使用相对路径或 `BASE_URL`，不得出现 `/assets/...` 这类根路径；push 到 `main` 由 GitHub Actions 自动构建部署；README 四段齐全（安装、运行、测试、访问地址）。
  - 验收：线上 `https://<user>.github.io/<repo>/` 打开首页；Network 中无 404；深链刷新可用；Actions 全绿。

- **R-17 语料质量**：构建脚本必须清洗站点广告、BOM/零宽字符、`第 N/M 页` 等噪音；同一章多版本按规则选一份；缺失章生成占位条目；输出 `quality-report.json` 记录候选数、缺失清单、选版与清洗统计、人工待审项；不得伪造正文、不得改章节号。页面「关于」必须说明缺失章数量与 `⚹` 占位来源。
  - 验收：`python tools/validate_corpus.py` 通过；`catalog.json` 中 3,233 条、缺失 132、可用 3,101；随机抽 20 章无广告行、无 BOM；缺失章 JSON 标记 `missing:true`。

- **R-18 性能**：阅读页首包 JS ≤110 KB gzip；首页动效按需懒加载且不影响首章可读；catalog ≤60 KB gzip；单章 ≤12 KB gzip；首页主图桌面 ≤250 KB、移动 ≤120 KB；移动 4G 模拟下 LCP ≤2.5 s、CLS ≤0.1、INP ≤200 ms；目录 3,233 项滚动不卡顿。
  - 验收：`npm run build` 报告与 Network 面板核对体积；Lighthouse 移动模拟达标；真机滚动目录无长任务。

- **R-19 可访问性**：全站可用键盘完成阅读、翻章、开关抽屉、调设置；焦点可见；图标按钮有 `aria-label`；抽屉/弹层有焦点陷阱与 `Esc` 关闭；正文为语义化标题与段落；进度条有可读文本；颜色对比度达标；提供「跳到正文」链接。
  - 验收：只用键盘从首页到第 2 章并打开设置；Tab 焦点始终可见；axe 扫描无 critical/serious 问题。

- **R-20 隐私与版权**：不接入任何统计、广告、第三方请求；不采集个人信息；数据只存本机；页面 `noindex,nofollow`，`robots.txt` 禁止抓取；关于页注明文本版权归原作者/出版方，站点仅个人阅读使用，可联系删除；不提供下载/导出全文功能。
  - 验收：Network 面板只有同源请求；`<meta name="robots" content="noindex,nofollow">` 存在；关于页可见版权说明。

## 6. 验收标准（场景表）

## 7. 非功能要求

- **兼容**：Chrome/Edge 最近两个大版本、Safari iOS 16+、Android Chrome 最近两个版本；微信内置浏览器保证可读（不保证安装 PWA）。
- **网络**：首次加载需联网；访问过的章节可离线；弱网 3G 下正文优先于动效，动效加载失败不影响阅读。
- **稳定**：任何单章加载失败只影响当前章；错误有中文文案与恢复路径；不出现白屏、死循环、无限重试。
- **可维护**：语料可重建；数据契约有版本；规则编号贯通；新增功能先改 spec。
- **体积**：仓库（不含原文）≤40 MB；构建产物 ≤35 MB；单文件 ≤5 MB。
- **隐私**：无统计、无追踪、无第三方请求、无账号。
- **版权**：`noindex`、`robots.txt`、关于页声明；不提供全文下载。

## 8. 运行与部署约束

- 本地开发：Node 24 + npm；`npm run dev`；数据先由 Python 脚本生成。
- 构建：`npm ci && npm run build`；CI 不重建语料，只校验已提交的 `public/data`。
- 部署：GitHub Pages（Actions），子路径 `/qzfs-reader/`；可选自定义域名。
- 语料重建：需要本机保留 `全法原本/` 原文（不入 git）；重建命令见 `docs/data-design.md`。
- 不做：服务端、数据库、登录、支付、广告、评论、多书。
