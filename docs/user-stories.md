# 全职法师阅读网站 · 用户故事

> 规则编号对应 `docs/requirements.md`。每条故事至少一个可验收结果。

## 读者

### US-01 继续上次阅读
作为读者，我想要一打开首页就能回到上次读到的地方，以便不用每次重新找章节。
- 规则：R-01、R-08
- 验收：读到第 12 章 50% → 回首页显示「继续阅读 · 第 12 章」→ 点击回到第 12 章 50% 附近。

### US-02 调到舒服的排版
作为读者，我想要调字号、背景、字体和行距，以便在白天、夜里、手机上都能舒服地读。
- 规则：R-03、R-04、R-05
- 验收：夜间主题 + 24 px + 行距 2.0 设置后刷新仍生效；首帧不闪白。

### US-03 快速找到某一章
作为读者，我想要按章节号或标题搜索，以便不用在 3,233 章里翻。
- 规则：R-06、R-10
- 验收：搜「2893」得到缺失标记；搜「世界」得到「第1章 世界大变」；点击结果直接打开。

### US-04 顺畅翻章
作为读者，我想要按钮、键盘、滑动和轮盘都能翻章，以便躺着、坐着、用电脑都能操作。
- 规则：R-07
- 验收：键盘 ←/→ 切章；手机滑动 80 px 切章；第一章上一章按钮禁用并提示。

### US-05 标记想回看的章节
作为读者，我想要给当前章加书签并在书架集中查看，以便回看名场面。
- 规则：R-09
- 验收：添加第 12 章书签 → 书架出现 → 刷新仍在 → 删除后消失。

### US-06 在手机上读得下
作为读者，我想要在 360–430 px 的手机上无横向滚动、按钮好点、抽屉好关，以便通勤时单手读。
- 规则：R-13、R-14
- 验收：390×844 全页面无横向滚动；按钮点击区 ≥44 px；抽屉 Esc/返回可关。

### US-07 没网也能接着读
作为读者，我想要已读过的章节在离线时还能打开，以便地铁/飞机上继续看。
- 规则：R-15
- 验收：访问第 1 章后开飞行模式，第 1 章可读；未访问的第 500 章提示「离线且未缓存」。

### US-08 低端设备不卡
作为读者，我想要旧手机/无 WebGL 时自动简化动效，以便页面不卡、不耗电。
- 规则：R-12、R-18
- 验收：模拟减少动态或禁用 WebGL → 首页仍有完整标题与主图，阅读功能正常，无报错。

### US-09 换设备不丢进度
作为读者，我想要导出/导入本地数据，以便换手机或换浏览器时迁移进度和书签。
- 规则：R-11
- 验收：导出 JSON → 清空 → 导入 → 设置/进度/书签恢复；导入损坏文件时原数据不变。

## 维护者

### US-10 重建语料
作为维护者，我想要一条命令把原文重新生成站点数据，以便原文更新或修正后快速上线。
- 规则：R-17
- 验收：`python tools/build_corpus.py ...` 生成 3,233 条目录、3,101 个正文文件、132 个缺失占位；`validate_corpus.py` 通过；质量报告含缺失与选版统计。

### US-11 一键部署
作为维护者，我想要 push 后自动构建并发布到 GitHub Pages，以便不用手动上传。
- 规则：R-16
- 验收：push 到 `main` → Actions 成功 → 线上 URL 打开首页与深链；手机可访问。

### US-12 知道文本哪里有问题
作为维护者，我想要看到缺失章清单、选版记录和清洗统计，以便决定补哪一章、改哪一处。
- 规则：R-17、R-20
- 验收：`quality-report.json` 列出 132 个缺失号、55 组标题冲突、清洗掉的广告行数；关于页对读者说明缺失数量。

### US-13 出问题能回退
作为维护者，我想要部署可回滚、数据可备份、错误有提示，以便线上出问题时快速恢复。
- 规则：R-11、R-16
- 验收：Pages 可回滚到上一版本；本地数据可导出备份；页面错误有重试/返回路径。
